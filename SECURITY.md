# Security policy

This project uses fictitious local CSV data and does not connect to HR, identity providers, cloud platforms, or business applications.

## Data handling

- Do not commit employee data, account inventories, credentials, or customer records.
- Use synthetic data for issues and demonstrations.
- Findings are review prompts, not proof of unauthorized access or a command to revoke an account.
- Account changes must remain under the organization's approved human review process; this tool does not perform them.

For project issues, open a GitHub issue using synthetic examples only. Remove identifiers and sensitive operational details.
